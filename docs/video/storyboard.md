# /brag plan — FollowUp

**What it is:** A free, open-source Windows work manager. It combines tasks, email follow-ups, calendar, automations and an AI assistant, and keeps all your data on your PC.
**Who it's for:** Freelancers, consultants, small-business owners and sales people who live in their inbox, and project leads who want ClickUp-style planning without a cloud.
**What sets it apart:** Follow-up sequences that chase non-repliers and stop the moment someone answers, all in one local SQLite file.
**Most impressive claim:** Five apps' worth of work (task manager, mail client, follow-up tool, calendar, AI chatbot) in one app. No cloud account, no telemetry, no subscription.
**Visual hook:** A question about the product's own name: "Who's following up on that email?" → "FollowUp is."
**Real UI shown:** All 16 screenshots from `docs/images/`. They show the real app with its own fictional demo workspace (`.example` domains, made-up people), so the video shows no real personal data.
**Tone:** `app-store`: clean feature cards and smooth slides, in FollowUp's own violet (#7b68ee) on its #f7f8fa surface, set in Inter.
**Share caption:** see `share-copy.txt`.

## Duration note
The user asked for **every feature** to be covered. That overrides the usual 15–25s rule, so the target is **50s** (25 bars at 120 BPM). Each feature still gets one clear beat.
